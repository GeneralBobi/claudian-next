# Claudian

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Existing Electron desktop application; local HTML, CSS and JavaScript. Extend the existing panel rather than replace its framework.

## Users

People using their own notes across AI applications, including people without technical setup knowledge. The companion should be understandable at a glance during ordinary desktop work.

## Product Purpose

User-owned, portable shared memory and a context-aware companion. Success means useful continuity and an appropriate next contact, not a larger collection of connection settings.

## Operating Context

The desktop is the visible surface. Existing Core context can provide a focus and contextual cards. Local notes are a bounded fallback, not the reasoning engine. No implied screen observation, listening, background model activity or automatic research.

## Capabilities and Constraints

1.0.0 is in development. Existing connection acceptance gaps remain explicit. No fake personal data or claim that a generated instruction creates a working connection. Feedback that only hides a cue must not mark a task complete or claim the AI learned it.

## Brand Commitments

Preserve Claudian identity and the accepted phrase “Bir asistandan, yol arkadaşına.” The user explicitly requests an expressive moving companion inspired by Loona and Hamroh: visible state and calm feedback, not a conventional AI chat panel. This authorizes motion in the companion despite the older no-motion design note.

## Evidence on Hand

Current implementation and planning documents; user-supplied Hamroh reference; personal project research reviewed without copying personal contents into the product. Hamroh imagery is reference only, not a licensed shipped asset.

## Product Principles

- Keep context and its source visible when useful.
- Let expression communicate a real state.
- Give attention back after a brief interaction.
- Preserve user control, privacy and note ownership.

## Accessibility & Inclusion

Visible text accompanies character states. All actions work by keyboard. Respect reduced motion and an explicit quiet mode. Errors remain legible without relying on color.

## Supported viewports

Desktop-only Electron surface. The web value above names the HTML/CSS rendering stack, not a mobile-web product. Complete supported evidence set: desktop.png (940×760), minimum.png (680×560; scrolling allowed). No mobile surface is shipped by this UI change.
