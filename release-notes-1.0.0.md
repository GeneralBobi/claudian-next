# Claudian 1.0.0

The new release continues from the 0.18.7 codebase in the separate claudian-next repository. It installs as Claudian Next with its own application identity and profile; 0.18.7 remains available as the legacy release.

## Available in this release
- Local Claude Desktop package setup for the selected Markdown/Obsidian folder.
- MCP-backed read/write verification and first-review reporting.
- Folder switching with stale proof invalidation; existing notes and legacy Claude configuration are preserved.
- Companion panel actions to complete or correct an explicit source-note item.
- Scoped connection revocation and distinct Next Codex MCP ownership groundwork.

## Current limits
General web/mobile connector distribution and other AI migration paths remain under development. Normal setup currently exposes local Claude Desktop. Shared public gateway/device pairing and the full context-driven companion are not complete. Technical checks do not replace real account acceptance.

## Windows download
Run Claudian-Next-Setup-1.0.0.exe. This installer is unsigned. Verify its SHA-256 using SHA256SUMS-1.0.0.txt. The installer includes the runtime.
